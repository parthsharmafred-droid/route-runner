# Route Runner

A phone-friendly delivery route app: street map, road-based route optimization, ETAs, tap-to-deliver checklist, and Google Maps navigation.

**Open it:** https://parthsharmafred-droid.github.io/route-runner/

On your phone, open the link and use **Add to Home Screen**. Routes and progress save on the phone; use Route settings > Save/Load backup file to move them. No customer data is stored in this repository.

Map: © OpenStreetMap contributors, © CARTO. Routing: OSRM. Address lookup: Nominatim.
